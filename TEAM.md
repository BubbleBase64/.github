## 🔄 Collaboration Patterns

### 🤖 **AI/ML Development Flow**
1. **@EceTugbaCebeci** designs and trains models
2. **@erdemerdogdu** assists with testing and validation
3. **@erdemerdogdu** integrates model outputs into frontend
4. **@keremdemirell** provides backend API support

### 🏗️ **Backend Development Flow**
1. **@keremdemirell** designs core backend services
2. **@ErdemAtila** develops architecture and data pipelines
3. **@erdemerdogdu** coordinates frontend integration needs
4. **@Bahoyvs** ensures deployment and scalability

1. **@erdemerdogdu** leads UI/UX development
