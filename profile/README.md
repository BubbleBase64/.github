# Bubbles Organization

**Bubbles** is an AI-powered academic project developed at **Bilkent University** with mentorship from **Amazon**.  
Our goal is to create an intelligent, bias-aware, and context-rich news platform that helps users consume news **critically, clearly, and consciously.**

---

## About the Project

Bubbles combines AI-driven summarization, bias detection, and timeline generation into a single ecosystem.  
It enables users to view stories from multiple perspectives and promotes transparency in digital media.

> **Mission:** Consume critically. Understand clearly. Engage consciously.
